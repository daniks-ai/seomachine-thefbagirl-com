### Вердикт

1. **Индийские кампании ($146, 51% расхода) — выключить.** Дешёвые клики ($0.30) с нулевой
   конверсией в канал/daniks. Индия не целевой рынок ни для канала (EN-контент под
   US-селлеров), ни для daniks.ai. Это «прогрев» только на бумаге — метрика клика без
   движения к цели. Урок напрямую применим к идее «дешёвой Бразилии»: дешевизна клика ≠
   ценность.
2. **DE Search ($141) — выключить или переделать.** CPC $1.86 — дорого; 0 конверсий; Maximize
   conversions на пустой истории конверсий = слив.
3. **EN Search — главный рынок, а кампания мертва**: Target CPA без истории конверсий не
   выигрывает аукционы → 0 показов. Симптом системный: кампании создавались, когда
   конверсии не работали (consent запрещал всё + labels не были вшиты).
4. **RU Search — оставить как эксперимент**: CPC $0.14, CTR 9%, единственная конверсия
   аккаунта. Бюджет крошечный, вреда нет.
5. Важная оговорка: 0 конверсий у DE/IN частично объясняется тем, что измерение заработало
   только 6 июля (региональный consent + импорт GA4-событий). Но связка «Индия + 21 секунда
   на сайте» — это не проблема измерения, это мусорный трафик.

## Часть 2. Ключевые факты ресёрча (28 источников, июль 2026)

**Meta ads по гео (CPM, Facebook):** США $16–23 · Бразилия $2.6–4.2 (в 5–8 раз дешевле,
подтверждено 3 независимыми источниками) · Мексика $3.5–4.5 · Индия $1–2.6.
НО: (а) бот/невалидный трафик в Индии и Бразилии на 20–30% выше, чем в Tier-1;
(б) дешёвый CPM ≠ дешёвый результат — конверсия в дешёвых гео ниже, интент на показ ниже;
(в) CPM Бразилии волатилен и растёт: $1.77 (авг 2025) → $9.73 (июнь 2026) — преимущество тает.

**Meta lookalike в 2026:** классические lookalikes живы, но при Advantage+ работают лишь как
«подсказка», которую алгоритм расширяет. Практический минимум seed-аудитории ~1 000 человек
(оптимум 5–10 тыс.). Advantage+ стабилен от ~50 конверсий/неделю. **У thefbagirl seed нет**:
трафик сайта — 382 сессии/28 дней, из них 79% — мусорный платный. Lookalike-стратегия
структурно недоступна, пока нет качественной базы.

**LGPD (Бразилия):** действует экстерриториально; Meta pixel на бразильских посетителях =
поведенческий мониторинг = под LGPD; ретаргетинг требует правового основания; согласие на
трекинг-пиксели — явное opt-in (штрафы до R$50 млн). Для BR-трафика с пикселем придётся
добавить BR в consent-баннер с denied-дефолтом.

**Цена подписчика YouTube (кейсы):** YouTube Promotions (Audience growth) ~$1/подписчик;
Demand Gen ~$2.19/подписчик; лучший кейс $0.27–0.31 (Tier-1, развлекательный канал — на
нишевый B2B не переносится). Просмотр: США ~$0.045, Бразилия ~$0.010.
**Главный риск:** платные подписчики почти не смотрят контент (у Promotions view-to-sub 44% —
признак «коллекционеров подписок»); мёртвые подписчики топят канал в рекомендациях.
У @AmazonFBAGirl симптом уже есть: 2 390 подписчиков, 27–58 просмотров на видео.

**Demand Gen «YouTube Engagements»:** оптимизируется прямо на подписки/просмотры, показывается
ТОЛЬКО залогиненным на YouTube, без мусорного инвентаря Video Partners. Рекомендация Google:
Maximize Conversions первые 14 дней → Target CPA после ~50 конверсий.

**Альтернативные каналы:** Reddit — медианный CPC $1.25, CPM ~$6.5, для B2B работает только
с нативным информационным креативом, вменяемый тест = $5k/мес на 90 дней (не наш бюджет;
органическая Reddit-стратегия уже есть в context/reddit-strategy.md + бонус AI-цитируемости).
TikTok — минималки $50/день кампания (не наш бюджет), креатив выгорает за 7–10 дней;
YouTube-клиенты имеют LTV на 67% выше TikTok-клиентов. Pinterest — нет данных по B2B/гео.

## Часть 3. Предложение

### Философия
Цель — прогрев, но прогрев измеряется не CPM и не количеством подписчиков, а «человек
посмотрел контент / дошёл до daniks.ai». Дешёвое гео без релевантного контента — повторение
Индии (проверено на своих деньгах: $146 → 0 конверсий). Канал болен не нехваткой подписчиков,
а тем, что подписчики не смотрят — лечить надо смотрибельностью.

### Трек 1 — YouTube-прогрев (основной, ~$12/день)
- **Demand Gen / YouTube Engagements** в Google Ads: продвигать 2–3 сильнейших ВИДЕО (не
  подписки), гео US (+UK/CA/AU), аудитории по интересам Amazon selling / e-commerce.
  Только залогиненный YouTube-инвентарь. Первые 14 дней Maximize Conversions.
- Микротест **YouTube Promotions** из Studio ($3–5/день): бенчмарк $1–2/подписчик, но
  еженедельно проверять, смотрят ли новые подписчики (YouTube Analytics). Не смотрят → стоп.
- KPI: engaged views (~$0.03–0.05/просмотр в US), удержание, рост «External/Ads» watch time.
  Подписчики — вторичная метрика.

### Трек 2 — BOFU-поиск на daniks.ai (~$10/день)
- Перезапустить «TheFBAGirl - EN - Amazon FBA Search»: убрать Target CPA (мёртвый холодный
  старт), поставить Maximize clicks, точные запросы «amazon ppc software / automation /
  best amazon ppc tools / <competitor> alternative», лендинги — best-tools/vs/review статьи,
  конверсия daniks_ai_click. После 30–50 конверсий → Maximize conversions.
- Единственный трек с прямой денежной отдачей (триалы daniks.ai через utm_source=thefbagirl).

### Трек 3 — дешёвое гео, но правильное: RU (+$5–8/день)
- «Бразилия по цене, но с релевантным контентом»: RU Search уже даёт CPC $0.14 и конверсию
  за $1.68, есть RU-канал @Amazon_FBA_Seller и RU-статьи. Поднять бюджет до $12–15/день,
  вести на RU-статьи с CTA на RU-канал.

### Meta pixel и Бразилия — фаза 2 (сентябрь), не сейчас
- Пиксель Meta поставить уже сейчас (бесплатно, копит аудитории с треков 1–2) + событийную
  разметку из dataLayer. CAPI — позже (нужен Worker на CF).
- BR добавить в consent-баннер (denied-дефолт) до любого BR-трафика — LGPD.
- Возвращаться к Meta/BR, когда: (а) пиксель накопил ≥1 000 качественных посетителей,
  (б) есть PT-контент для прогрева (у канала его нет; у daniks.ai есть /pt/ — но это их
  кампании). До этого Meta-lookalike технически не на чем строить.

### Чего НЕ делать
- Не покупать подписчиков в дешёвых гео (Индия-2, топит рекомендации).
- Не запускать TikTok/Reddit ads на этом бюджете (минималки/порог теста).
- Не ставить Target CPA на кампании без истории конверсий.
- Не оценивать успех по CPC/CPM — только по целевым действиям.

### Бюджет и контроль
~$25–30/день ≈ $750–900/мес на всё. Еженедельный чек: engaged views, youtube_channel_click,
daniks_ai_click, смотрибельность новых подписчиков. Первые 2 недели — без правок. Через
4 недели — решение по перераспределению бюджета между треками.
