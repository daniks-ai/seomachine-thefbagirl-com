# TheFBAGirl Target Keywords & Topic Clusters

This document organizes TheFBAGirl's target keywords by topic cluster for content planning and SEO optimization. It supports the Amazon FBA and e-commerce space Katia operates in.

**Important**: Volumes and difficulty scores below are seed estimates based on SERP observation. Before committing to a cluster, refresh numbers with the `/research-serp [keyword]` command and DataForSEO integration. Update this file with confirmed data after each research pass.

---

## Topic Cluster Structure

Each cluster includes:
- **Pillar Keyword**: High-volume, competitive seed term.
- **Cluster Keywords**: 5–10 supporting subtopics.
- **Long-Tail Keywords**: 10–15 specific queries.
- **Search Intent**: informational, commercial, or transactional.

## Usage Guidelines

### When Writing New Content
1. Identify which cluster the article belongs to.
2. Pick the appropriate pillar or long-tail keyword.
3. Ensure primary keyword lands in H1, first 100 words, 2+ H2s, and conclusion.
4. Sprinkle LSI keywords naturally across the article.
5. Link to sibling content within the cluster (3–5 internal links).
6. Add the new article to `internal-links-map.md` after publishing.

### When Planning Content Calendar
1. Prioritize high-opportunity keywords with matching YouTube videos (lowest effort, highest quality).
2. Balance news-cycle articles (Cluster 10) with evergreen (Clusters 1–9, 11–12).
3. Aim for one cornerstone article per cluster before spreading into long-tail.
