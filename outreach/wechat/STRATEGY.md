# WeChat-стратегия продвижения daniks.ai (путь C)

Дата: 2026-07-23. Статус: есть ОБА аккаунта — личный WeChat Кати и
верифицированный Service Account ($99/yr). Это операционный план, как из
них вырастить канал продаж для китайских Amazon-селлеров.
Стартовый чек-лист первых 2 недель — в конце документа.

Связанные документы: [CHINA_SELLERS_SOURCES.md](../CHINA_SELLERS_SOURCES.md)
(источники селлеров, Tier 3 = точки входа в WeChat-группы),

## Почему WeChat, а не что-то ещё (фиксация выводов)

- 250k+ китайских селлеров на Amazon.com, 31.8% — Шэньчжэнь. Email у них
  вторичен, Google не используется. Весь B2B-цикл — знакомство, прогрев,
  демо, оплата, саппорт — китайские продавцы SaaS ведут **в личных чатах
  WeChat и группах**.
- B2B-продажа в Китае ≠ self-serve. Никто не купит подписку с лендинга.
  Покупают у «человека в вичате», которому доверяют. Поэтому центр воронки —
  **личный аккаунт (人设 = персона-бренд)**, а не сайт.

## Три уровня присутствия (в порядке запуска)

### 1. Личный аккаунт (есть сейчас) — ядро воронки
Роль: нетворк в группах, 1:1 продажи, Moments (朋友圈) как «витрина доверия».

**Критично — прогрев.** Свежие аккаунты, зарегистрированные из-за рубежа,
Tencent банит за любую активность, похожую на спам. Первые 3–4 недели:
- НЕ добавлять больше 5–10 контактов в день, НЕ рассылать одинаковые сообщения.
- Вести себя как человек: переписки с реальными знакомыми, 2–3 поста
  в Moments в неделю, привязать карту (сильно повышает траст аккаунта),
  подписаться на десяток OA, полистать 视频号.
- Идеальный первый круг: попросить существующих знакомых/клиентов с WeChat
  добавить её — входящие добавления безопаснее исходящих.

**Оформление профиля (нужен китаец-редактор или хотя бы вычитка):**
- Имя: латиница + короткий китайский ник, например `Katia | Daniks AI 广告托管`.
- Аватар — реальное фото (лицо = траст, особенно «иностранка, которая делает
  инструмент для Amazon PPC» — это дифференциатор, а не минус).
- Signature: одна строка ценности + «亚马逊广告AI托管» (AI-autopilot для
  амазон-рекламы).

### 2. Официальный аккаунт (公众号, Service Account) — ЕСТЬ (верифицирован, $99/yr)
Зачем: находимость в 搜一搜 (внутренний поиск WeChat), статьи как
материал для шаринга в группы (шарить статью ОА — норм, шарить «купите
наш тул» — бан), меню с QR личного аккаунта, автоответы. Это «сайт внутри
WeChat»: без ОА бренд выглядит несуществующим.

**Ключевая механика лимитов**: 4/мес — это лимит **群发 (broadcast,
пуш всем подписчикам)**. Обычная публикация статьи через **发布 (publish)**
— БЕЗ лимита: статья получает постоянный URL, видна на странице аккаунта,
её можно шарить в группы/личку/Moments. То есть контент-запас строим
неограниченно через 发布, а 4 пуша/мес бережём под самое важное
(запуски, сильные кейсы).

### 3. 视频号 (Channels) — потом, если вообще
Для зарубежных аккаунтов доступ ограничен и нестабилен. Отложить до момента,
когда будет ОА + человек, который сможет адаптировать YouTube-контент.
Не тратить время сейчас.

## Фазы

### Фаза 0 — прогрев + инфраструктура (недели 1–4, $0)
1. Прогрев личного аккаунта (см. выше). Привязать карту.
2. **Проверить, открывается ли daniks.ai из мейнленда** (Cloudflare из Китая
   работает нестабильно): chinafirewalltest.com / 17ce.com. Если сайт лежит
   или грузится >5 сек — это блокер для всей воронки, решать до масштабирования
   (вариант: лёгкая zh-страница на быстром для Китая CDN).
3. **zh-лендинг daniks.ai**: страница на упрощённом китайском с WeChat QR
   вместо «Book a demo» (Calendly в Китае — трение; китайский лид хочет
   «добавь меня в вичате»).
4. **Оплата**: проверить, включён ли Alipay в Stripe-аккаунте. Китайский
   селлер с корпоративной картой Visa — редкость; без Alipay потеряем
   часть оплат.
5. Материалы для 1:1 продаж: PDF/лонг-скриншоты (长图) на китайском —
   кейс «до/после ACoS», прайсинг, FAQ. В Китае продают пересылаемыми
   картинками в чат, не ссылками.

### Фаза 1 — вход в сообщества (недели 3–8, $0 + время)
Цель: 100–200 релевантных контактов в личном аккаунте, присутствие в 5–10
живых группах.

Точки входа (из Tier 3 карты источников):
- **Global From Asia WeChat FBA группы** — англоязычный мостик, вход простой,
  там же ловить инвайты в китайские группы.
- **知无不言 / AMZ123 / 卖家之家** — у статей и профилей авторов часто
  указан WeChat группового админа; вход в группы через «假装萌新» нельзя —
  честно: «делаю AI-тул для PPC, отвечаю на вопросы про рекламу».
- **Официальные амазоновские группы новых селлеров** (gs.amazon.cn публикует
  QR) — море новичков с болью по PPC.
- Каждый лид из немецкой/EN Instantly-кампаний с китайскими корнями →
  переводить в WeChat.

**Правила выживания в группах** (китайские группы банят жёстче Facebook):
- 2–4 недели только полезные ответы про PPC, ноль ссылок.
- Продавать в группе нельзя вообще. Схема: полезный ответ в группе →
  человек сам добавляет в личку → продажа 1:1.
- Красные конверты (红包) по праздникам — дёшево и сильно греет статус в группе.

### Фаза 2 — контент-машина (месяцы 2–4, ~$500–1100/мес)
1. **Нанять фрилансера-нейтива** (~$400–1000/мес, Wise) — план из
   wechat_content_hire: сорсинг через 知无不言/AMZ123-вакансии. Роль:
   4 статьи/мес для ОА + ведение Moments + первичные ответы в группах
   под надзором Кати. Идеальный профиль: экс-оператор амазон-аккаунтов
   (运营), которых в Шэньчжэне тысячи, а не «маркетолог».
2. **Зарегистрировать ОА** ($99/год) на юрлицо daniks.
3. Контент: перевод-адаптация лучших EN-статей + чисто китайские темы
   (кейсы ACoS, разборы правил Amazon для китайских селлеров, сравнение
   с китайскими тулами 卖家精灵/店小秘 — «а у них нет AI-автопилота ставок»).
   Позиционирование: «инструмент, которым пользуются западные селлеры —
   теперь на китайском» (западность = преимущество, признак качества).
4. Moments-ритм личного аккаунта: 3–5 постов/нед — скрины результатов
   клиентов, жизнь продукта, немного личного (人设 без личного не работает).

### Фаза 3 — платное усиление (месяцы 4+, от $500/мес точечно)
Только когда воронка (группы → личка → демо → оплата) проверена руками:
- **软文 (нативные статьи) в больших селлерских ОА** — AMZ123, 卖家之家 и
  десятки нишевых; у AMZ123 есть прямой рекламный кабинет. Типичный чек
  ¥3–15k за публикацию. Начать с 1–2 тестов, мерить добавления в личку по QR.
- **KOL-партнёрки**: авторы селлерских ОА за рев-шер (реплика нашей
  партнёрской модели 25% lifetime из Instantly-кампаний).
- **Baidu** (отдельный трек из baidu_ads_entry: реселлер Nanjing MG,
  ~$1k депозит) — включать только если WeChat-воронка подтвердит спрос.
- Moments Ads / WeChat Ads — НЕ трогать: порог от ¥50k, нужен местный
  агент, для нас преждевременно.

## Воронка целиком

```
группы/форумы/软文/QR на лендинге
        → добавление в ЛИЧНЫЙ аккаунт (единая точка)
        → 1:1: боль по ACoS → 长图-кейс + скрин-демо
        → триал (аккаунт заводим за них в звонке/чате)
        → оплата (Alipay через Stripe)
        → клиент → инвайт в клиентскую группу → рефералы
```

Клиентская WeChat-группа (клиенты + Катя + саппорт) — стандарт китайского
SaaS: удержание + соцдоказательство + источник рефералов.

## KPI по фазам

| Фаза | Метрика | Цель |
|---|---|---|
| 0 | аккаунт жив, карта привязана, сайт открывается из CN | да/нет |
| 1 | контактов в личке / живых групп | 100–200 / 5–10 |
| 2 | подписчики ОА / добавления в личку с ОА-статей | 300+ / 20+/мес |
| 2–3 | демо-чатов в мес → платящих | 10 → 1–2 первых |
| 3 | CAC из 软文 (¥ за добавление в личку) | <¥100 |

## Риски

1. **Бан личного аккаунта** = потеря всей базы контактов. Митигация:
   дисциплина прогрева, никаких массовых рассылок, со временем — второй
   аккаунт (контентщика) как резерв; клиентов дублировать в группу ОА.
2. **Сайт недоступен из Китая** — проверить в Фазе 0, это тихий убийца
   конверсии.
3. **Языковой барьер в 1:1** — до найма нейтива продаёт Катя с переводчиком
   (медленно, но для первых 10 демо ок; встроенный перевод WeChat среднего
   качества, для продающих сообщений — прогонять через Claude).
4. **Ценовая чувствительность** — китайские тулы дешевле. Не конкурировать
   ценой; продавать «западный AI-автопилот» и экономию времени оператора.
