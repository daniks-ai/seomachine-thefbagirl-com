## Методика и верификация

- Емейлы только из опубликованных владельцем источников: футеры/страницы контактов, оферты и политики (у СНГ-школ емейл юрлица в оферте — опубликованный контакт), About-страницы YouTube, RSS подкастов (`itunes:email`). Скрейпленные из платных баз адреса исключены.
- Cloudflare-обфусцированные (profit-zone) декодированы из `data-cfemail` в HTML их собственных страниц; penguin-team извлечён curl'ом (сайт отдаёт 403 ботам, емейл в их HTML).
- Подписчики YouTube — через YouTube Data API 2026-08-10; Telegram — tgstat/telemetr/превью t.me.
- Сырые данные YouTube-поиска (176 каналов): scratchpad `channels_raw.json` / `channels_detail.json` — на случай второго круга.
- Instantly дополнительно верифицирует емейлы при импорте — bounce-риск фильтруется там.
